# 青鸟 Qingniao

[English](README.md) | **简体中文**

> 本地优先的 macOS 效率工具 —— 常驻菜单栏，`⌥ Space` 唤起。

青鸟把「找应用、找文件、算数、执行常用系统动作」收进一个统一搜索入口，
并在本机保存剪贴板历史。没有账号，没有云同步，没有埋点。

## 功能

### `⌥ Space` 统一搜索

居中命令栏，四类结果并发返回，最多展示 12 条：

| 来源 | 说明 |
| --- | --- |
| **应用** | 扫描 `/Applications`、`~/Applications`、`/System/Applications`，回车启动 |
| **文件** | 默认搜索桌面、文稿、下载；回车打开，`⌘Enter` 在 Finder 中显示，`⌘C` 复制完整路径 |
| **计算** | 本机解析数学表达式与单位换算，结果可复制 |
| **内置命令** | 12 条预先登记的安全动作，见下表 |

搜索支持中英文关键词、拼音与拼音首字母（如输入 `xtsz` 命中「系统设置」）。
空查询时展示「常用操作」与「最近使用」，排序依据仅保存在本机。

命令栏始终出现在**指针所在的显示器**上，多屏环境下不需要移动鼠标去找窗口。

### `⌥⌘C` 剪贴板历史

- 记录文本、富文本、图片与 Finder 文件引用；一次复制多种表示时只存一条
- 重复内容按摘要合并，更新最近出现时间
- 支持搜索、类型筛选、置顶、收藏、预览、复制、单条删除
- 保留期可选 7 天 / 30 天 / 90 天 / 永久，默认 30 天
- 可随时暂停记录；清空全部记录需二次确认
- 文件记录只保存路径与元数据，**不复制文件内容**；源文件失效时标记为不可用

剪贴板历史搜索是窗口内的独立搜索，与统一搜索互不干扰 ——
统一搜索只通过「剪贴板」这一条内置命令打开历史窗口。

### 内置命令

| 类别 | 命令 |
| --- | --- |
| 导航 | 打开系统设置、打开本应用设置、打开下载目录、打开应用程序目录、打开桌面目录 |
| 剪贴板 | 打开剪贴板历史、清空剪贴板历史、暂停或恢复剪贴板记录 |
| 系统 | 检查权限状态、重启 Finder、重启 Dock、切换深色或浅色模式 |

只执行预先登记的固定动作，**不解析也不执行任意 Shell 命令**。
清空剪贴板历史、重启 Finder、重启 Dock 需要二次确认。

### `⌥⌘,` 设置中心

四个页面：**通用**（插件管理、外观、语言、数据占用、权限状态）、
**快速启动**（文件搜索目录与索引状态）、**剪贴板**（记录开关、保留期、清空）、
**关于**（版本、更新、反馈、隐私政策、开源许可）。

功能以「第一方插件」形式接入，可在「通用 → 插件管理」中单独启用或禁用；
单个插件启动失败时其余功能继续运行，失败原因与重试入口保留在列表中。

界面语言提供「跟随系统」「简体中文」「English」，修改后立即生效。

## 隐私

青鸟是本地优先的，默认不联网：

- 剪贴板内容、使用频率、设置全部保存在本机
  `~/Library/Application Support/Qingniao/`
- 无账号系统、无云同步、无埋点后端、无支付通道
- 文件索引在本地建立，不上传文件名或路径
- 反馈仅由你主动发邮件触发；应用生成的邮件包含版本号、构建号、macOS 版本
  和你的备注，**不附带**剪贴板历史、截图、文件或崩溃日志

完整内容见 [隐私政策](PRIVACY.md)。

### 权限

青鸟只申请实际用到的权限，并在申请前解释用途：

| 权限 | 用途 | 申请时机 |
| --- | --- | --- |
| **辅助功能** | 键鼠模拟、自动粘贴、窗口控制 | 首次使用相关功能时按需申请 |
| **Apple Events** | 执行需要跨应用控制的内置命令 | 首次执行该类命令前申请 |
| **剪贴板** | macOS 不为剪贴板读取单独弹窗 | 默认开启，可随时暂停或清空 |

拒绝任何权限都不会阻止你进入应用；对应功能会保持不可用状态，
并提供「授权」「重新检测」「打开系统设置」三个入口。

## 未来计划

### 截图与贴图（开发中，当前版本未开放）

统一截图入口，一个快捷键进入截图状态，由指针位置和鼠标操作自动判定模式：

- 悬停窗口 → 窗口截图；悬停菜单栏或桌面空白 → 当前显示器全屏；按住拖拽 → 区域圈选
- 区域圈选优先级高于悬停默认值，无论从窗口还是菜单栏起拖
- 指针移动到其他显示器时，目标判定跟随切换
- 标注支持矩形、箭头、直线、折线、文字、马赛克
- 取色；复制、保存（系统面板，PNG / JPEG）、快捷保存（固定目录，PNG）
- 全显示器叠层与截图状态下的快捷键提示
- **贴图**：把截图或剪贴板内容变成置于其他窗口上方的悬浮窗口，
  支持缩放、透明度、隐藏、关闭、恢复队列与销毁

截图会话结束即释放，产品不保留截图历史记录，也不自动清理你保存的图片文件。

### 右键扩展（规划中）

把青鸟的能力接入系统右键菜单，让常用动作在你当前的上下文里直接可用，
而不必先唤起命令栏。

### 其他方向

- 自动检查更新（当前仅手动跳转 Releases 页面，不做后台联网）
- 截图 OCR 文字识别

> 路线图中的功能与时间均为计划，不构成承诺。截图相关代码已实现并通过测试，
> 目前由功能开关关闭，待发布前完成真机多屏、TCC 与签名验收后开放。

## 常见问题

**青鸟免费吗？**
个人非商业用途免费，不含支付、订阅、许可证密钥或账号。商业用途需要单独授权。

**为什么找不到截图功能？**
截图正在收尾验收，当前版本未开放。开放后会出现在菜单栏、快捷键和设置中。

**会上传我的剪贴板吗？**
不会。剪贴板历史、设置与使用频率全部保存在本机，不联网、不同步、不上传。

**可以关闭剪贴板记录吗？**
可以。在「设置 → 剪贴板」暂停记录，或用内置命令「暂停或恢复剪贴板记录」。

**支持任意 Shell 命令吗？**
不支持。只有 12 条预先登记的内置命令，不接受用户输入的命令。

**在 Mac App Store 上架了吗？**
没有。仅通过 GitHub Releases 分发，采用 Developer ID 签名并经过 Apple 公证。

**会占用 `⌥ Space` 与 Spotlight 冲突吗？**
青鸟不会自动改你的系统快捷键。若检测到冲突，设置页会给出提示，
你可以为青鸟改绑其他快捷键。

**支持多显示器吗？**
命令栏出现在指针所在的显示器上。截图的多显示器支持随截图功能一同开放。
