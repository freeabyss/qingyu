# 清羽 Qingyu

[English](README.md) | **简体中文**

> 本地优先的 macOS 效率工具 —— 常驻菜单栏，`⌥ Space` 唤起。

清羽把「找应用、找文件、算数、执行常用系统动作」收进一个统一搜索入口，
并在本机保存剪贴板历史。没有账号，没有云同步，没有埋点。

## 功能

### `⌥ Space` 统一搜索

居中命令栏。结果来源为 **应用、命令、计算、文件、设置**；
**默认不把剪贴板历史混入搜索**（历史请用 `⌥⌘C` 或内置命令「打开剪贴板历史」）。

| 来源 | 说明 |
| --- | --- |
| **应用** | 扫描 `/Applications`、`~/Applications`、`/System/Applications`，回车启动 |
| **文件** | 默认搜索桌面、文稿、下载；回车打开，`⌘C` 复制路径 |
| **计算** | 本机解析数学表达式与单位换算 |
| **命令** | 预先登记的内置动作（见下表） |
| **设置** | 跳转到对应设置页 |

- 支持中英文关键词、拼音与拼音首字母
- 匹配质量：左匹配（前缀）> 右匹配（后缀）> 中间匹配；输入框**无**放大镜图标
- 空查询：仅展示 **最近使用** 与 **收藏**（无独立「常用操作」块）
- 命令栏出现在**指针所在的显示器**上

### `⌥⌘C` 剪贴板历史

无标题栏窗口：通栏搜索 + 类型筛选（**全部 / 文本 / 图片 / 文件**），
左侧列表 + 右侧详情。

- 记录文本（含富文本，统一显示为 **文本**）、图片与 Finder 文件引用
- 列表图标优先显示**来源应用**（如 Arc、Safari）
- 行内操作常显：置顶、复制、删除；文件另有 **在 Finder 中显示**
- 原图缺失的图片项不进入列表；文件不存在时 Toast 提示，不会静默无响应
- 重复内容按摘要合并；保留期 7 / 30 / 90 天或永久（默认 30 天）
- 文件记录只保存路径与元数据，**不复制文件内容**

剪贴板搜索仅在该窗口内；命令栏默认不搜索剪贴板（可在设置中调整搜索源）。

### 内置命令

| 类别 | 命令 |
| --- | --- |
| 导航 | 打开系统设置、打开本应用设置、打开下载目录、打开应用程序目录、打开桌面目录、打开访达 |
| 剪贴板 | 打开剪贴板历史、清空剪贴板历史、暂停或恢复剪贴板记录 |
| 系统 | 检查权限状态、重启 Finder、重启 Dock、切换深色或浅色模式、锁定屏幕、睡眠、重新启动 Mac、关机 |

只执行预先登记的固定动作，**不解析也不执行任意 Shell 命令**。
危险 / 电源类命令需要二次确认。

### `⌥⌘,` 设置中心

页面：**通用**（外观、语言、开机启动、权限、数据）、
**快速启动**（快捷键、搜索源、文件搜索目录）、**剪贴板**（记录开关、保留期、清空）、
**关于**。

- 外观：跟随系统 / 浅色 / 深色
- 菜单栏：打开搜索、剪贴板历史、设置、退出（关于在设置内）

界面语言：跟随系统 / 简体中文 / English。

## 隐私

清羽是本地优先的，默认不联网：

- 剪贴板内容、使用频率、设置全部保存在本机
  `~/Library/Application Support/Qingyu/`
- 无账号系统、无云同步、无埋点后端、无支付通道
- 文件索引在本地建立，不上传文件名或路径
- 反馈仅由你主动发邮件触发；应用生成的邮件包含版本号、构建号、macOS 版本
  和你的备注，**不附带**剪贴板历史、截图、文件或崩溃日志

完整内容见 [隐私政策](PRIVACY.md)。

### 权限

| 权限 | 用途 | 申请时机 |
| --- | --- | --- |
| **辅助功能** | 键鼠模拟、窗口控制 | 首次使用相关功能时按需申请 |
| **Apple Events** | 跨应用内置命令（如睡眠 / 重启 / 关机） | 首次执行该类命令前申请 |
| **剪贴板** | macOS 不为剪贴板读取单独弹窗 | 默认开启，可随时暂停或清空 |

拒绝任何权限都不会阻止你进入应用。
