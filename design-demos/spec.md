# 清羽 Qingyu · UI Demo 设计 spec

## 这是什么
清羽是一款 macOS 效率工具：全局快捷键唤出命令栏搜索（应用/文件/命令/设置/网页），
历史剪贴板，区域截图与标注，贴图。本次交付**纯 HTML 高保真 demo**，用于方向评审，
不涉及应用代码改动。

## 受众与场景
- 受众：每天用键盘工作 8 小时以上的 macOS 用户（开发、设计、写作）。
- 场景：屏幕中间短暂停留 3–10 秒的「快进快出」操作；剪贴板窗口是长时间停留的检索与整理；
  设置是低频但需要一眼看懂的配置。
- 情感基调：安静、利落、值得信任。不喧闹，不像营销页。

## 核心信息（demo 必须让评审看懂的）
1. **命令栏**：一次输入就能分辨「这是什么」（类型：应用/命令/设置）、「回车会发生什么」（⏎ 提示）。
2. **剪贴板**：列表 + 详情双栏；复制是带文字的主动作；删除按需出现。
3. **设置**：插件化管理，功能开关与状态（运行中/已停止）同屏可见。

## 输出格式与尺寸（三版统一，便于横比）
- 桌面展示板：1440×900，单文件 HTML（无外部依赖，字体走系统栈）
- 板内三块真实界面，尺寸按 PRD：命令栏 760×560、剪贴板 860×520、设置 920×640
  （按 0.82 缩放摆入板内，保持比例）
- 同一份真实内容，三版只换设计与骨架

## 已知约束
- 不编造数据：结果项、剪贴板条目都用真实产品里的文案与路径
- 可读性底线：正文 ≥14px、标签 ≥12px、正文对比度 ≥4.5:1
- 不做炫技动画；只做能表达状态与层级的过渡

## 素材需求
- T0 档：不依赖外链图片。壁纸/缩略图用 CSS 渐变与真实应用图标形状绘制（诚实降级）。
- 不做 logo 仿制：应用图标用系统风格色块 + 单字，不冒充真实品牌图标。
