# 清羽 Qingyu macOS 规范

## Menu Bar

1. 应用运行时常驻菜单栏，使用适配深浅色的单色 template 图标。
2. 菜单按顺序提供：打开搜索、剪贴板、截图、设置、欢迎向导、关于、退出。
3. 菜单栏截图入口进入统一截图状态；菜单栏剪贴板入口打开独立历史窗口。
4. 图标可显示新剪贴板内容提示；提示不改变菜单项顺序。

## Dock

1. 应用以 Agent App 运行，`LSUIElement` 保持为 `true`。
2. 启动和窗口关闭后不显示 Dock 图标。
3. 用户关闭全部窗口后，菜单栏和全局快捷键继续可用。

## Shortcut

| 动作 | 默认全局快捷键 | 规则 |
|---|---|---|
| 打开命令栏 | `⌥ Space` | 再次触发时关闭 |
| 剪贴板 | `⌥⌘C` | 激活剪贴板窗口、清空上次搜索关键词并聚焦搜索框 |
| 打开设置 | `⌥⌘,` | 打开上次设置页 |
| 开始截图 | `F1` | 进入统一截图状态，依据指针位置和鼠标操作自动确定窗口、全屏或区域截图 |
| 贴图或恢复最近关闭贴图 | `F3` | 读取当前剪贴板；存在恢复项时按最近关闭顺序恢复 |
| 显示或隐藏全部贴图 | `⇧F3` | 保持各贴图原有状态 |
| 切换贴图鼠标穿透 | 用户录制 | 优先作用于指针下贴图 |

1. 全局快捷键均可重录和恢复默认值。
2. 注册前检测应用内部及已知系统快捷键冲突。
3. 注册失败时保留旧绑定，显示冲突原因和重新录制入口。
4. 插件注册快捷键时使用同一冲突检测与设置界面。

## Window Level

| 窗口 | 类型与层级 |
|---|---|
| 命令栏 | 可获得键盘焦点的无边框 `NSPanel`，`.floating` |
| 剪贴板 | 标准 `NSWindow`，窗口标题为“剪贴板” |
| 设置 | 标准 `NSWindow` |
| 欢迎向导 | 标准 `NSWindow` |
| 截图选择叠层 | 无边框全屏窗口；捕获期间高于其他清羽窗口 |
| 截图预览与标注 | 无边框浮动 `NSPanel` |
| 贴图 | 始终置顶的独立窗口 |

命令栏和截图叠层高于普通窗口；截图叠层在捕获期间拥有最高交互优先级。

## Space

1. 命令栏可加入所有 Space，并可在全屏应用上方显示。
2. 截图选择叠层在当前 Space 覆盖所有已连接显示器。
3. 贴图跨 Space 可见，并可显示在全屏应用上方。
4. 剪贴板、设置和欢迎向导遵循标准 macOS 窗口的 Space 行为。

## Multi-display

1. 进入截图状态时，为每个已连接显示器创建截图叠层。
2. 指针所在显示器是当前截图显示器；指针跨越显示器边界后立即切换。
3. 当前截图显示器负责窗口检测、区域选择、全屏选择、放大镜、工具条和快捷键提示。
4. 截图裁剪支持 Retina 缩放、显示器负坐标和不同缩放比例组合。
5. 选区、放大镜、工具条和快捷键提示始终限制在当前截图显示器内；选区最小为 `5×5` 像素。
6. `⌘A` 只选择当前截图显示器的完整像素区域。
7. 显示器连接、断开或排列变化后，当前截图会话重新建立叠层和坐标映射。
8. 命令栏每次打开时使用指针所在显示器；无法确定时回退到 `NSScreen.main`。

## Permission

| 权限 | 使用时机 | 用户路径 |
|---|---|---|
| 屏幕录制 | 首次显示欢迎向导时 | 欢迎向导主动请求；用户拒绝或暂不授权时，截图入口仍提供授权、系统设置与重新检测 |
| 辅助功能 | 首次显示欢迎向导时 | 欢迎向导主动请求；用户拒绝或暂不授权时，相关能力入口提供授权、系统设置与重新检测 |
| Apple Events | 用户首次执行需要跨应用控制的已登记内置命令前 | 按需请求授权；拒绝后显示受影响命令、重新检测与系统设置入口；欢迎向导不申请 |
| 用户选择文件读写 | 用户选择快捷保存目录或普通保存文件时 | 快捷保存目录使用仅允许选目录的系统文件夹选择器；普通保存使用系统保存面板获取范围明确的文件访问权 |

“设置 → 截图 → 打开保存截图文件夹”在目录不存在时先创建目录，再使用 Finder 打开当前快捷保存目录；打开时定位目录本身，若已有该目录窗口则激活并复用；创建或打开失败时仅在设置操作按钮旁显示本地化的“无法打开保存截图文件夹：{系统原因}”错误并保留当前目录配置。按钮不显示处理中或禁用状态，重复触发只执行一次。清羽不自动删除该目录中的截图文件。该入口只查看已保存文件，不读取或生成截图历史。

1. 每个插件声明所需权限及用途；应用在用户触发对应能力时请求权限。
2. 权限撤销后，受影响功能进入权限缺失状态，其他功能继续运行。
3. 应用重新激活时刷新正在等待的权限状态。

## Sandbox

1. App Sandbox 保持关闭，以支持主目录文件检索和 Apple Events 系统命令。
2. Hardened Runtime、Developer ID 签名和 Apple Notarization 用于发布版本。
3. Entitlements 只包含实际使用的系统能力。
4. 内置命令必须通过已登记动作调用；第一方插件与主应用共享已获得的系统权限和本地数据访问边界，不提供进程级隔离。

## App lifecycle

1. 首次启动创建应用核心，加载内置插件和本地设置，然后显示欢迎向导。
2. 完成或跳过欢迎向导后，注册全局快捷键、同步开机启动状态并按设置启动剪贴板监听。
3. 普通启动完成初始化后进入菜单栏常驻状态。
4. 打开功能时按需创建对应窗口；重复打开时激活已有窗口。
5. 命令栏每次打开时重置焦点和查询会话；关闭后释放面板状态。
6. 剪贴板历史和设置窗口关闭后隐藏并复用。
7. 截图叠层、预览和标注窗口在完成或取消会话后释放；截图完成后不保留运行期截图历史。
8. 插件启用时注册能力并启动必要任务；禁用时注销入口、快捷键和后台任务。
9. 应用退出时停止剪贴板监听和插件任务，注销全局快捷键，销毁贴图及恢复队列，并完成本地数据写入。
10. 开机启动使用 macOS `SMAppService`，状态由欢迎向导和设置共同管理。
