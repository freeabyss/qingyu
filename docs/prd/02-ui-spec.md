# 清羽 Qingyu UI 规范

## 页面原型

### 命令栏

```text
┌────────────────────────────────────────────────────────────┐
│ 🔍 查询                                        [Esc 关闭] │
├────────────────────────────────────────────────────────────┤
│ 图标  标题                         类型 / 说明      ↩︎     │
│ 图标  标题                         类型 / 说明             │
├────────────────────────────────────────────────────────────┤
│ 来源 / 状态                                  键盘提示      │
└────────────────────────────────────────────────────────────┘
```

输入区始终位于顶部，为无边框裸输入框，仅由一条细线与结果区分隔（静止 1pt 描边、聚焦加厚为 2pt 强调色）；不与结果区叠加独立分隔线。结果区显示图标、标题、类型和说明。空查询时不显示任何内容区，命令栏只有输入框；输入字符后才出现结果区。截图作为一个统一结果出现，不拆分区域、窗口和全屏入口。结果按稳定标识去重。
操作频率仅用于本机排序，不上传、不跨设备同步、不写入剪贴板历史，也不保存截图内容。
设置中不提供清除或重置搜索排序所依赖的使用频率记录的入口。
命令栏每次打开时在指针所在显示器的可见区域内水平居中，输入行顶边位于可见区中心上方（默认 336pt）；无法确定指针所在显示器时回退到 `NSScreen.main`。收起（只有输入框）与展开（显示结果）共用同一输入行顶边锚点：输入文字时输入框位置不变，结果列表只在其下方展开；可见区装不下时整体收拢进可见区。
命令栏展示应用、文件、计算、内置命令结果，以及关键词触发的网页搜索结果，不展示剪贴板记录或设置项，也不提供来源开关、来源筛选控件及 `⌘1–⌘6` 来源快捷键。“剪贴板”是唯一与剪贴板相关的命令；“系统设置”命令打开 macOS 系统设置应用，不打开清羽自身设置；不提供“打开本应用设置”或“检查权限状态”命令。空查询不展示任何内容区；截图以单一结果出现，并与系统控制命令置于同一列表，不按风险等级拆分分区。

从统一搜索执行任何内置命令（包括“重启 Finder”“重启 Dock”“重启系统”“关机”“注销”）均直接执行，不显示二次确认。
其中关机、重启系统、注销等高风险命令在结果行显示风险提示或危险图标，但不增加确认步骤；重启 Finder、重启 Dock 不显示风险图标。
命令执行失败时在结果区域显示错误；Apple Events 权限被拒绝时，结果标记为不可用并提供授权、重新检测和系统设置入口。风险图标提供本地化辅助功能标签。
回车、鼠标点击和结果快捷键均视为统一搜索执行路径，遵循直接执行规则。
重启系统、关机和注销命令直接调用 macOS 系统动作，不显示倒计时或撤销控件。
从菜单栏、设置按钮或其他专用入口执行系统控制命令时显示二次确认；用户取消确认时不执行命令。
确认对话框使用动作专属文案，默认焦点位于“取消”；取消后关闭对话框，不执行命令且不改变命令状态。
“重启系统”“关机”“注销”固定显示对应中英文名称；命令搜索支持中英文关键词、中文拼音和拼音首字母，别名不替换结果显示名称。
应用和内置命令从 1 个字符开始检索，文件从 2 个字符开始检索；计算结果仅在输入可解析时出现。

### 剪贴板

```text
┌────────────────────────────────────────────────────────────┐
│ 🔍 搜索       [筛选] [暂停/恢复] [设置]                   │
├────────────────────────────────────────────────────────────┤
│ 内容预览                         类型  时间       [复制]   │
│ 内容预览                         类型  时间       [复制]   │
├────────────────────────────────────────────────────────────┤
│ 记录数量 / 记录状态                                      │
└────────────────────────────────────────────────────────────┘
```

历史窗口采用左右双栏：左侧为记录列表，右侧为选中内容的阅读区；详情区宽 360pt。搜索栏只筛选已保存的剪贴板记录，不调用统一搜索；至少输入 2 个字符，匹配纯文本、富文本纯文本内容、文件名和文件路径时忽略大小写及重音。复制为主要行内动作；预览和删除按需显示。剪贴板记录不提供置顶或收藏状态。通过统一搜索、菜单栏或快捷键打开剪贴板时，窗口激活、清空上次搜索关键词并自动聚焦搜索框。
历史窗口不提供“清空全部”入口；该操作只在“设置 → 剪贴板”中提供，并在执行前确认。
“设置 → 剪贴板”明确提示：清羽会记录所有可读取的受支持内容，包括密码等敏感内容；数据仅保存在本机。

### 截图与标注

```text
┌────────────── 当前指针显示器截图叠层 ──────────┐
│                                                │
│        ┌──── 自动高亮窗口 / 拖拽选区 ────┐     │
│        │                                  │     │
│        └──────────────────────────────────┘     │
│ [快捷键提示]   [形状][文字][马赛克][复制][保存]│
└────────────────────────────────────────────────┘
```

进入截图状态后，鼠标停留在窗口上默认高亮并选中该窗口；鼠标停留在最上方菜单栏或桌面空白区域时默认选中当前显示器全屏；按住左键圈选区域后自动截取圈选区域。只要发生拖拽，区域圈选优先于窗口或全屏默认值，无论拖拽起点位于窗口、菜单栏还是桌面。单击高亮目标执行窗口或全屏截图。指针跨显示器时，高亮和截图上下文切换到对应显示器。左下角固定显示当前状态可用的快捷键；选区锁定后，工具条优先放在选区下方居中，空间不足时放在上方。放大镜跟随选区操作显示。

截图完成后不保留截图历史。用户可在“设置 → 截图”点击“打开保存截图文件夹”，由 Finder 查看已保存文件。

### 贴图

```text
┌─────────────────────────────┐
│                             │
│        剪贴板内容           │
│                             │
└─────────────────────────────┘
```

贴图只显示内容，操作通过键盘、鼠标和上下文菜单完成；选中或悬停时显示必要的边界和状态反馈。

### 设置

```text
┌────────────┬───────────────────────────────────────────────┐
│ 通用       │ 页面标题                                      │
│            │                                               │
│ 功能列表   │ 设置项                         控件 / 状态     │
│  快速启动  │ 设置项                         控件 / 状态     │
│  剪贴板    │                                               │
│  截图      │                                               │
│            │                                               │
│ 关于       │                                               │
└────────────┴───────────────────────────────────────────────┘
```

设置默认显示 5 个页面：通用、快速启动、剪贴板、截图、关于。“功能列表”是侧栏分组标题；被禁用或启动失败的插件不显示对应功能页面。内容区按“说明、当前状态、操作”组织设置项。

| 页面 | 内容 |
|---|---|
| 通用 | 插件管理、外观、语言、数据、权限及其他应用级设置；外观提供“跟随系统”“浅色”“深色”，默认跟随系统，修改后即时保存并同步已打开窗口；语言提供“跟随系统”“简体中文”“English”，默认跟随系统，修改后立即切换；跟随系统遇到不支持的语言时回退到 English；数据区域显示清羽全部本地数据占用空间，并提供打开数据目录，不提供重置或清空全部数据；插件行显示名称、版本、状态和启用开关，失败时显示原因与重试操作 |
| 快速启动 | 搜索入口、应用/文件/计算/内置命令/网页搜索/AI 对话六类固定来源、自定义文件搜索目录、关键词跳转目录、结果行为和快捷键；输入 `<关键词> <文字>` 时提供一条打开对应网页的结果并排在首位，内置目录覆盖 Google、Bing、百度、GitHub、Wikipedia、ChatGPT、Claude 等四十余个站点，用户可改写任一内置条目的关键词或追加自定义条目（可填 URL 模板与是否支持预填）；站点原生支持 URL 预填时直接带文字打开，否则打开站点并把文字放入剪贴板、在结果行提示粘贴发送；目录行显示索引状态和刷新/移除操作；自定义目录不限制位置、磁盘、数量或类别，只检查重复和父子覆盖；不提供来源开关、来源筛选、搜索黑名单或隐藏结果管理 |
| 剪贴板 | 记录开关、保留期（7 天、30 天、90 天或永久，默认 30 天）、多表示内容优先级、文件集合、历史行为、清空全部记录和快捷键；缩短保留期不提示，过期记录在启动满一小时后的首次清理或后续每小时清理时删除 |
| 截图 | 截图、标注、贴图、保存、快捷保存目录、打开保存截图文件夹和快捷键；快捷保存目录默认是系统图片目录，仅可通过文件夹选择器设置，取消目录选择时保留原值，成功选择后立即生效，修改目录不迁移旧截图；目录路径完整展示，空间不足时仅视觉截断；“打开保存截图文件夹”在 Finder 中打开当前快捷保存目录，目录不存在时先自动创建，创建失败或配置指向文件时仅显示错误提示并保留当前目录配置，成功后不额外显示 Toast；清羽不自动清理或删除该目录中的截图文件；“保存”打开以该目录为初始位置的系统保存面板，默认填入可修改的 `Screenshot-YYYYMMDD-HHmmss` 文件名（不含扩展名），切换 JPEG/PNG 时仅改变自动追加的扩展名，默认 PNG 并可选 JPEG/PNG（JPEG 固定 90% 质量，透明区域铺白），PNG 保留透明度，扩展名由格式自动追加并校验文件名符合系统要求；“快捷保存”始终写入 PNG 并显示 2 秒“图片已保存到 {完整目录路径}”提示 |
| 关于 | 当前版本与构建号、手动更新检查、反馈、隐私政策和开源许可；手动检查打开项目 GitHub Releases 页面，不提供后台自动更新检查状态或开关 |

“开机启动”默认开启，用户可在向导中直接修改；屏幕录制和辅助功能权限在向导阶段主动请求，拒绝或暂不授权不阻断“开始使用”进入应用，受影响能力随后显示权限缺失状态。设置变更即时保存。标题和底部操作区固定；中间内容可滚动。

## 窗口尺寸

| 窗口 | 尺寸要求 |
|---|---|
| 命令栏 | 宽 760；空查询（只有输入框）时高 56；显示结果时高 560 |
| 剪贴板 | 初始 `860×520`；最小 `720×420`；可缩放；窗口和页面标题统一为“剪贴板” |
| 设置 | 初始及最小 `920×640`；侧栏宽 200；可缩放 |
| 欢迎向导 | 最小 `720×520`；理想 `720×620`；可放大 |
| 截图选择叠层 | 每个已连接显示器各覆盖一个完整像素区域 |
| 截图预览与标注 | 随截图内容适配；最大 `1100×820` |
| 贴图 | 截图贴图完整保持原截图位置和尺寸；剪贴板图片保持宽高比且宽、高不超过当前操作显示器可见区域的 40%；剪贴板文本、HTML、颜色和文件路径初始 `420×280`；最小 `80×60` |

窗口在系统文字放大后应保持主要操作可见；内容超出时使用滚动区域。

## 控件

| 控件 | 要求 |
|---|---|
| 搜索框 | 打开窗口后自动获得焦点；清楚显示输入、占位文字和清除动作 |
| 结果行 | 显示图标、标题、类型或说明；整行可选择；选中态具有明确对比 |
| 主按钮 | 每个页面只突出当前主动作 |
| 图标按钮 | 提供本地化辅助功能标签和悬停说明 |
| 开关 | 标签说明控制对象；状态修改后即时保存 |
| 快捷键录制器 | 显示当前组合、录制状态、冲突原因和恢复默认入口 |
| 权限卡片 | 同时显示权限用途、当前状态和下一步操作 |
| 确认对话框 | 明确动作对象、影响和确认按钮；破坏性按钮使用危险语义色 |
| Toast | 说明已完成动作或失败原因；错误信息包含下一步操作 |
| 标注工具条 | 将标注工具与复制、保存、贴图等终局动作分组 |
| 截图快捷键提示 | 固定在当前指针显示器左下角；随窗口选择、区域选择和标注状态更新 |

所有页面使用 Jade 的颜色、字体、间距、圆角、材质和阴影 token。布局采用 4 点间距基准；系统深浅色和文字大小变化时保持内容可读。

### 视觉语言：极简、轻质感、扁平化 + 轻拟物

- 以留白、对齐与细分隔线组织信息；不使用彩色图标块、重卡片阴影或重复的装饰徽章。
- 主体为中性灰白／炭黑，强调色为低饱和蓝灰；旧 `Jade` 名称只保留为代码 API，不再代表青绿色主题。
- 强调文字色：浅色 `#4D6487`、深色 `#B2C4DF`；选中底色：浅色 `#ECF0F6`、深色 `#2A3443`。白字主按钮另用较深底色，保证可读性。
- 设置：独立品牌导航区、单色导航图标、清晰的页标题与说明、限宽内容列和平整分组；所有插件页复用同一布局。
- 命令栏：空查询时面板只有裸输入框（无边框、无分隔线、无内容区）；输入后出现单条细线（静止 1pt、聚焦加厚为强调色）与 52pt 结果行、真实应用图标和轻量类型文字；只有选中行展示回车提示。
- 剪贴板：标题与搜索工具栏、轻量类型页签、左侧列表与右侧固定宽度阅读区；复制是带文字的主动作，其余操作为图标。
- 轻拟物只体现在按钮的微弱接触阴影、边缘高光和浮窗的柔和投影；内容组不加投影。
- 圆角使用 6 / 8 / 10 / 12 / 16pt 层级；正文保持系统语义字体，页标题 26pt，命令栏输入 19pt。
- 焦点通过边线厚度反馈，筛选通过下划线与字重反馈，错误与风险保留图标和语义色。

实施与验证记录见 [Task 010](../tasks/010-interface-refinement.md)。


## 状态

| 状态 | 展示要求 |
|---|---|
| 加载 | 保留页面结构并显示正在处理的对象 |
| 空结果 | 保留查询内容并说明可调整的条件 |
| 初始空态 | 不展示内容区，命令栏只有输入框 |
| 暂停 | 说明当前功能已暂停并提供恢复按钮 |
| 权限缺失 | 说明受影响功能，提供授权、重新检测和系统设置入口 |
| 快捷键冲突 | 保留原快捷键，行内显示冲突组合和重新录制入口 |
| 部分失败 | 保留可用结果，单独标记失败来源 |
| 文件目录索引中 | 保留其他来源和已完成目录的结果；目录行显示“索引中”及进度反馈 |
| 文件目录不可用 | 保留目录配置，暂停该目录结果并提供刷新和移除操作；目录恢复后自动重建索引 |
| 快捷保存目录不可用 | 保留当前截图会话，说明目录不可写或无法访问，并提供重试及打开截图设置入口；不自动切换到其他目录 |
| 保存截图文件夹创建失败 | 在操作按钮旁以内联文字显示本地化的“无法打开保存截图文件夹：{系统原因}”错误；保留当前快捷保存目录配置，不自动改写目录，也不提供重试按钮 |
| 插件启动失败 | 插件管理中的启用开关保持开启，显示失败原因和重试操作；对应功能页面和其他贡献隐藏 |
| 不可用内容 | 显示内容及不可用原因，禁用对应主动作 |
| 破坏性确认 | 显示影响范围，等待用户明确确认 |
| 操作成功 | 更新页面状态；快捷保存成功显示“图片已保存到 {完整目录路径}”提示 2 秒后自动消失 |

截图设置中的“打开保存截图文件夹”按钮不显示处理中或禁用状态；重复点击在 300ms 防抖窗口内只执行一次；开始下一次目录操作时清除上一次内联错误。

状态不能仅依赖颜色表达。动效使用 120–200ms 淡入或状态过渡；系统开启“减弱动态效果”时取消位移动画。

## 键盘操作

### 通用窗口

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 移动列表选择 |
| `Enter` | 执行主动作 |
| `Esc` | 关闭浮层、取消当前操作或返回上一状态 |
| `⌘,` | 打开设置 |
| `⌘W` | 关闭当前标准窗口 |

### 命令栏与剪贴板

| 按键 | 行为 |
|---|---|
| 输入字符 | 更新搜索结果 |
| `Enter` | 执行选中结果或复制选中的剪贴板记录 |
| `⌘Enter` | 统一搜索选中文件时，在 Finder 中显示该文件 |

## 交互

1. 命令栏打开时聚焦搜索框；失焦、点击外部或按 `Esc` 后关闭。
2. 结果选择变化后立即更新主动作提示；执行成功后关闭命令栏或进入目标窗口。
3. 菜单栏、命令栏和全局快捷键触发同一功能时，进入同一状态和窗口。
4. 剪贴板筛选收拢在搜索栏筛选菜单中；暂停状态提供原位恢复入口。
5. 截图仅有一个入口；进入截图状态后，窗口悬停默认选中窗口，菜单栏悬停默认选中当前显示器全屏，按住左键圈选后自动截取区域；单击高亮目标执行窗口或全屏截图。
6. 指针进入其他显示器后，该显示器成为当前截图显示器并更新窗口高亮、放大镜和快捷键提示。
7. 截图选区锁定后保持原位；复制、保存、快捷保存或贴图完成会话。
8. 由截图创建贴图时，贴图窗口沿用原截图区域并保持原位，不在创建完成后重新居中或偏移。
9. 从剪贴板创建贴图时，首张位于当前操作显示器中央；后续贴图依次向右下偏移 `24 pt`，到达边缘后从中央重新开始。
10. 左下角快捷键提示只显示当前状态可执行的操作，并在状态变化时立即更新。
11. 标注图案结束后通过撤销和重做恢复；文字支持缩放、旋转和按住 `⇧` 恢复水平。
12. 系统设置授权完成并返回应用后，权限状态自动重新检测。
13. 欢迎向导的开始和跳过操作始终可见；跳过操作先确认。
