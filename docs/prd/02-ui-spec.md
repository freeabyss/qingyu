# 青鸟 Qingniao UI 规范

## 页面原型

### 命令栏

```text
┌────────────────────────────────────────────────────────────┐
│ 🔍 查询                                        [Esc 关闭] │
├────────────────────────────────────────────────────────────┤
│ 图标  标题                         类型 / 说明      ↩︎     │
│ 图标  标题                         类型 / 说明             │
├────────────────────────────────────────────────────────────┤
│ 来源 / 状态                                  键盘提示      │
└────────────────────────────────────────────────────────────┘
```

输入区始终位于顶部。结果区显示图标、标题、类型和说明；空查询显示常用操作、最近使用和收藏。

### 剪贴板历史

```text
┌────────────────────────────────────────────────────────────┐
│ 🔍 搜索       [筛选] [暂停/恢复] [清空] [设置]            │
├────────────────────────────────────────────────────────────┤
│ 内容预览                         类型  时间       [复制]   │
│ 内容预览                         类型  时间       [复制]   │
├────────────────────────────────────────────────────────────┤
│ 记录数量 / 记录状态                                      │
└────────────────────────────────────────────────────────────┘
```

列表采用单列结构。复制为主要行内动作；置顶、收藏、预览和删除按需显示。

### 截图与标注

```text
┌────────────── 当前指针显示器截图叠层 ──────────┐
│                                                │
│        ┌──── 自动高亮窗口 / 拖拽选区 ────┐     │
│        │                                  │     │
│        └──────────────────────────────────┘     │
│ [快捷键提示]   [形状][文字][马赛克][复制][保存]│
└────────────────────────────────────────────────┘
```

进入截图状态后高亮指针所在窗口。指针跨显示器时，高亮和截图上下文切换到对应显示器。左下角固定显示当前状态可用的快捷键；选区锁定后，工具条优先放在选区下方居中，空间不足时放在上方。放大镜跟随选区操作显示。

### 贴图

```text
┌─────────────────────────────┐
│                             │
│        剪贴板内容           │
│                             │
└─────────────────────────────┘
```

贴图只显示内容，操作通过键盘、鼠标和上下文菜单完成；选中或悬停时显示必要的边界和状态反馈。

### 设置

```text
┌────────────┬───────────────────────────────────────────────┐
│ 通用       │ 页面标题                                      │
│            │                                               │
│ 功能列表   │ 设置项                         控件 / 状态     │
│  快速启动  │ 设置项                         控件 / 状态     │
│  剪贴板    │                                               │
│  截图      │                                               │
│            │                                               │
│ 关于       │                                               │
└────────────┴───────────────────────────────────────────────┘
```

设置共 5 个页面：通用、快速启动、剪贴板、截图、关于。“功能列表”是侧栏分组标题。内容区按“说明、当前状态、操作”组织设置项。

| 页面 | 内容 |
|---|---|
| 通用 | 外观、语言、数据、权限及其他应用级设置 |
| 快速启动 | 搜索入口、搜索来源、结果行为和快捷键 |
| 剪贴板 | 记录开关、保留周期、历史行为和快捷键 |
| 截图 | 截图、标注、贴图、保存和快捷键 |
| 关于 | 当前版本与构建号、更新、反馈、隐私政策和开源许可 |

### 欢迎向导

```text
┌────────────────────────────────────────────────────────────┐
│                         青鸟                               │
│                 一句话说明产品用途                        │
├────────────────────────────────────────────────────────────┤
│ 搜索快捷键                                                 │
│ 剪贴板记录                                                 │
│ 开机启动                                                   │
│ 屏幕录制权限                                               │
│ 辅助功能说明                                               │
├────────────────────────────────────────────────────────────┤
│ [跳过设置]                  [开始使用]       [隐私政策]    │
└────────────────────────────────────────────────────────────┘
```

标题和底部操作区固定；中间内容可滚动。

## 窗口尺寸

| 窗口 | 尺寸要求 |
|---|---|
| 命令栏 | 宽 760；收起高 128；显示结果时高 560 |
| 剪贴板历史 | 初始 `680×520`；最小 `680×460`；可缩放 |
| 设置 | 初始及最小 `920×640`；侧栏宽 200；可缩放 |
| 欢迎向导 | 最小 `720×520`；理想 `720×620`；可放大 |
| 截图选择叠层 | 每个已连接显示器各覆盖一个完整像素区域 |
| 截图预览与标注 | 随截图内容适配；最大 `1100×820` |
| 贴图 | 按内容比例和目标显示器可见区域确定初始尺寸；最小尺寸和默认占屏比例待确认 |

窗口在系统文字放大后应保持主要操作可见；内容超出时使用滚动区域。

## 控件

| 控件 | 要求 |
|---|---|
| 搜索框 | 打开窗口后自动获得焦点；清楚显示输入、占位文字和清除动作 |
| 结果行 | 显示图标、标题、类型或说明；整行可选择；选中态具有明确对比 |
| 主按钮 | 每个页面只突出当前主动作 |
| 图标按钮 | 提供本地化辅助功能标签和悬停说明 |
| 开关 | 标签说明控制对象；状态修改后即时保存 |
| 快捷键录制器 | 显示当前组合、录制状态、冲突原因和恢复默认入口 |
| 权限卡片 | 同时显示权限用途、当前状态和下一步操作 |
| 确认对话框 | 明确动作对象、影响和确认按钮；破坏性按钮使用危险语义色 |
| Toast | 说明已完成动作或失败原因；错误信息包含下一步操作 |
| 标注工具条 | 将标注工具与复制、保存、贴图等终局动作分组 |
| 截图快捷键提示 | 固定在当前指针显示器左下角；随窗口选择、区域选择和标注状态更新 |

所有页面使用 Jade 的颜色、字体、间距、圆角、材质和阴影 token。布局采用 4 点间距基准；系统深浅色和文字大小变化时保持内容可读。

## 状态

| 状态 | 展示要求 |
|---|---|
| 加载 | 保留页面结构并显示正在处理的对象 |
| 空结果 | 保留查询内容并说明可调整的条件 |
| 初始空态 | 展示常用操作或开始使用的方法 |
| 暂停 | 说明当前功能已暂停并提供恢复按钮 |
| 权限缺失 | 说明受影响功能，提供授权、重新检测和系统设置入口 |
| 快捷键冲突 | 保留原快捷键，行内显示冲突组合和重新录制入口 |
| 部分失败 | 保留可用结果，单独标记失败来源 |
| 不可用内容 | 显示内容及不可用原因，禁用对应主动作 |
| 破坏性确认 | 显示影响范围，等待用户明确确认 |
| 操作成功 | 更新页面状态；只在结果不可直接观察时显示 Toast |

状态不能仅依赖颜色表达。动效使用 120–200ms 淡入或状态过渡；系统开启“减弱动态效果”时取消位移动画。

## 键盘操作

### 通用窗口

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 移动列表选择 |
| `Enter` | 执行主动作 |
| `Esc` | 关闭浮层、取消当前操作或返回上一状态 |
| `⌘,` | 打开设置 |
| `⌘W` | 关闭当前标准窗口 |

### 命令栏与剪贴板

| 按键 | 行为 |
|---|---|
| 输入字符 | 更新搜索结果 |
| `Enter` | 执行选中结果或复制选中的剪贴板记录 |
| `Esc` | 关闭窗口且保留应用运行 |

### 截图与标注

| 按键 | 行为 |
|---|---|
| `Tab` | 切换窗口或界面元素检测；使用直线工具时切换直线与箭头 |
| `` ` `` / `!` | 切换后续截图是否捕获指针 |
| `⌘A` / `R` | 选择当前截图显示器全屏 / 恢复上次成功区域 |
| `,` / `.` | 上一条 / 下一条成功截图 |
| `W/A/S/D` | 将指针移动 1 像素；拖选时调整选区 |
| 方向键 | 将选区或贴图移动 1 像素 |
| `⌘` + 方向键 | 扩大对应选区边界 1 像素 |
| `⇧` + 方向键 | 缩小对应选区边界 1 像素 |
| `⌥` | 强制显示放大镜 |
| `C` / `⇧C` | 复制 Hex / RGB 颜色值 |
| 空格 | 显示或隐藏标注工具条 |
| `⌘Z` / `⌘Y` | 撤销 / 重做 |
| `⇧⌘Z` | 清除全部标注并确认 |
| `⌘C` / `Enter` | 复制截图并结束会话 |
| `⌘S` / `⇧⌘S` | 保存 / 快捷保存并结束会话 |
| `⌘T` | 创建贴图并结束截图会话 |
| `⌘P` | 打开系统打印面板 |
| 滚轮、`1/2`、`[/]` | 在编辑模式调整画笔粗细 |
| 右键 | 结束当前标注；无活动标注时重置选区或取消 |

### 贴图

| 按键或操作 | 行为 |
|---|---|
| `1` / `2` | 顺时针 / 逆时针旋转 90° |
| `3` / `4` | 水平 / 垂直翻转 |
| 滚轮、`+/-`、拖动边缘 | 在 10%–800% 范围缩放 |
| `⌘` + 滚轮、`⌘+/-` | 在 10%–100% 范围调整不透明度 |
| 中键 | 恢复 100% 缩放和不透明度 |
| `⇧` + 左键双击 | 切换缩略图模式 |
| `Esc` / 左键双击 / `⌘W` | 关闭并进入恢复队列 |
| `⇧Esc` | 销毁贴图 |
| `⌘V` | 使用当前剪贴板有效内容替换贴图 |
| `⇧⌘C` | 从文本或 HTML 贴图复制纯文本 |
| `⇧⌘P` | 打开截图与贴图设置 |

全局快捷键见 [03-macos-spec.md](03-macos-spec.md)。

## 交互

1. 命令栏打开时聚焦搜索框；失焦、点击外部或按 `Esc` 后关闭。
2. 结果选择变化后立即更新主动作提示；执行成功后关闭命令栏或进入目标窗口。
3. 菜单栏、命令栏和全局快捷键触发同一功能时，进入同一状态和窗口。
4. 剪贴板筛选收拢在搜索栏筛选菜单中；暂停状态提供原位恢复入口。
5. 进入截图状态后自动高亮指针所在窗口；单击选择该窗口，按住左键拖拽改为区域选择，`⌘A` 选择当前显示器全屏。
6. 指针进入其他显示器后，该显示器成为当前截图显示器并更新窗口高亮、放大镜和快捷键提示。
7. 截图选区锁定后保持原位；复制、保存、快捷保存或贴图完成会话。
8. 左下角快捷键提示只显示当前状态可执行的操作，并在状态变化时立即更新。
9. 标注图案结束后通过撤销和重做恢复；文字支持缩放、旋转和按住 `⇧` 恢复水平。
10. 系统设置授权完成并返回应用后，权限状态自动重新检测。
11. 欢迎向导的开始和跳过操作始终可见；跳过操作先确认。
