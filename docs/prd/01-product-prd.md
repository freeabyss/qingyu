## 产品定位

青鸟是本地优先、可扩展的 macOS 效率工具。产品以统一搜索、菜单栏和全局快捷键为稳定入口，将搜索、剪贴板、截图、系统操作等能力组织为相互独立的插件模块。

应用核心负责插件生命周期、入口路由、权限协调、设置和本地数据边界。新增能力通过插件接入，并可出现在统一搜索、菜单栏、快捷键和设置中。所有插件均由项目所有者开发和维护。

## 用户场景

| 用户 | 场景 | 结果 |
|---|---|---|
| 办公用户 | 在当前工作中快速启动应用、查找文件或计算 | 通过统一搜索直接完成操作 |
| 知识工作者 | 找回复制内容，处理截图并发送 | 通过剪贴板历史、截图和贴图完成处理 |
| 高级用户 | 调用常用系统动作并组合更多效率能力 | 通过受控命令和插件获得扩展能力 |

## 功能范围

| 模块 | 功能 |
|---|---|
| 应用核心 | 插件注册、启停、生命周期、入口路由、权限协调、设置和错误隔离 |
| 统一搜索 | 聚合插件结果、排序、键盘选择、执行主动作、展示最近使用与收藏 |
| 应用与文件 | 启动应用，按文件名或路径查找并打开文件，在 Finder 中显示文件 |
| 计算 | 计算本地数学表达式与单位换算 |
| 剪贴板 | 记录、搜索、复制、预览、置顶、收藏、删除和清空文本、图片及文件引用 |
| 截图 | 统一截图入口；区域、窗口和当前显示器全屏截图；像素级选区、取色、标注、复制、保存和打印 |
| 贴图 | 将剪贴板内容贴到屏幕，支持变换、透明度、分组、隐藏、关闭、恢复和销毁 |
| 系统命令 | 搜索并执行产品登记的系统、截图和剪贴板命令 |
| 设置 | 提供通用、快速启动、剪贴板、截图、关于 5 个页面 |
| 欢迎向导 | 设置搜索快捷键、剪贴板记录、开机启动和截图权限 |

界面要求见 [02-ui-spec.md](02-ui-spec.md)，macOS 集成要求见 [03-macos-spec.md](03-macos-spec.md)。

## 功能规则

### 插件

1. 每个插件具有稳定且唯一的标识、显示名称、版本、启用状态和能力声明。
2. 插件通过应用核心注册搜索结果、命令、菜单项、快捷键、设置项和所需权限。
3. 单个插件失败时，应用核心和其他插件继续运行，并向用户显示可执行的处理方式。
4. 禁用插件后，应用核心注销该插件提供的入口、快捷键和后台任务，并保留用户配置。
5. 内置功能遵循与扩展插件相同的能力边界。
6. 插件开发权限仅归项目所有者；插件由项目所有者签名并发布。

### 统一搜索

1. 启用的插件并发返回结果；单个来源失败不影响其他结果。
2. 排序由来源优先级、文本匹配度和本地使用记录共同决定，最多展示 12 条结果。
3. 空查询时展示常用操作、最近使用和收藏。常用操作包含剪贴板历史与截图入口。
4. 回车执行选中结果的主动作；改变系统状态的动作先确认。
5. “打开剪贴板历史”打开独立历史窗口；剪贴板记录的主动作是复制该记录。

### 应用、文件与计算

1. 应用来源扫描 `/Applications`、`~/Applications` 和 `/System/Applications` 中的应用。
2. 文件来源默认搜索 `~/Desktop`、`~/Documents` 和 `~/Downloads`，排除隐藏目录、缓存及 `Library`。
3. 文件主动作是打开，次级动作是在 Finder 中显示；失效文件显示为不可用。
4. 计算在本机完成，结果可复制。

### 剪贴板

1. 默认记录文本、图片和文件引用，默认保留 30 天；用户可修改保留期或暂停记录。
2. 重复内容按内容摘要合并，并更新出现时间。
3. 文件记录保存路径和元数据；源文件失效时将记录标记为不可用。
4. 数据保存在当前 macOS 用户设备。用户可删除单条记录或清空全部记录。
5. 清空全部记录前必须确认；持久化失败不得改变当前系统剪贴板。

### 截图与贴图

1. 区域、窗口和全屏截图共用一个入口和同一个截图状态。
2. 进入截图状态后自动高亮指针所在窗口；单击选择该窗口，按住左键拖拽改为区域选择，`⌘A` 选择指针所在显示器全屏。
3. 指针移动到其他显示器时，窗口检测、区域选择和全屏选择切换到该显示器。
4. 截图完成复制、保存、快捷保存或贴图后记为成功截图。成功截图进入当前运行期的截图记录。
5. 截图记录按成功时间排序，容量范围为 `1…200`，默认 20；满额时淘汰最早记录。
6. 标注支持矩形、箭头、直线、折线、文字和马赛克。导出内容只包含已完成的标注。
7. 贴图按图像、颜色、HTML、纯文本、文件路径的顺序解析剪贴板内容。
8. HTML 以本地富文本渲染；脚本和远程资源保持禁用。
9. 文件路径首次贴图时按设置解析本地图片；其他情况显示路径文本。
10. 关闭贴图后按最近关闭顺序进入恢复队列。恢复数量范围为 `0…20`，默认 1；销毁和关闭分组会永久移除对应贴图。
11. 截图记录、贴图和恢复队列只保留到本次应用退出。
12. 截图、复制、保存、打印或贴图失败时保留当前可编辑状态并提供重试。

### 系统命令

1. 系统命令由应用或插件明确登记，用户输入只用于检索已登记命令。
2. 清空剪贴板历史、重启 Finder、重启 Dock 等改变状态的命令执行前必须确认。
3. 命令使用系统 API 或 Apple Events 执行；系统拒绝时显示原因和处理入口。
4. 命令使用记录只参与本地排序。

### 设置与欢迎向导

1. 设置包含 2 个固定页面：通用、关于。
2. 功能列表包含 3 个功能页面：快速启动、剪贴板、截图；每个功能独立管理自己的设置。
3. 通用页面管理外观、语言、数据、权限等应用级设置。
4. 自研插件需要用户配置时，在功能列表注册一个独立设置页面。
5. 设置修改即时保存到当前用户设备；无效配置保持原值。
6. 首次启动显示单屏欢迎向导；“开始使用”和“跳过设置”均记录完成状态。
7. 跳过欢迎向导前必须确认；关闭或未完成向导不阻断其他功能入口。
8. 通用页面的权限区域展示当前状态、重新检测和系统设置入口。
9. 关于页面读取当前 Bundle 版本与构建号，并提供更新、反馈、隐私政策和开源许可入口。
