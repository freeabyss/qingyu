## 产品定位

青鸟是本地优先、可扩展的 macOS 效率工具。产品以统一搜索、菜单栏和全局快捷键为稳定入口，将搜索、剪贴板、截图、系统操作等能力组织为相互独立的第一方插件。

应用核心负责第一方插件生命周期、入口路由、权限协调、设置和本地数据边界。新增能力通过第一方插件接入，并可出现在统一搜索、菜单栏、快捷键和设置中。插件仅由项目所有者开发，随青鸟一同安装、升级和卸载；当前产品不加载用户或第三方安装的插件。

## 用户场景

| 用户 | 场景 | 结果 |
|---|---|---|
| 办公用户 | 在当前工作中快速启动应用、查找文件或计算 | 通过统一搜索直接完成操作 |
| 知识工作者 | 找回复制内容，处理截图并发送 | 通过剪贴板历史、截图和贴图完成处理 |
| 高级用户 | 调用常用系统动作并组合更多效率能力 | 通过受控命令和内置功能获得扩展能力 |

## 功能范围

| 模块 | 功能 |
|---|---|
| 应用核心 | 第一方插件注册、启停、生命周期、入口路由、权限协调、设置和故障隔离 |
| 统一搜索 | 聚合应用、文件、计算和内置命令结果，完成排序、键盘选择和主动作执行，并展示常用操作与最近使用 |
| 应用与文件 | 启动应用，按文件名或路径查找并打开文件，在 Finder 中显示文件 |
| 计算 | 计算本地数学表达式与单位换算 |
| 剪贴板 | 记录、搜索、复制、预览、删除和清空文本、图片及文件引用 |
| 截图 | 统一截图入口；区域、窗口和当前显示器全屏截图；像素级选区、取色、标注、复制和保存 |
| 贴图 | 将截图或剪贴板内容显示为置于其他窗口上方的临时悬浮窗口，支持变换、透明度、分组、隐藏、关闭、恢复和销毁 |
| 内置命令 | 搜索并执行产品预先登记的导航、截图、剪贴板和系统控制动作 |
| 设置 | 提供通用、快速启动、剪贴板、截图、关于 5 个页面 |
| 欢迎向导 | 设置搜索快捷键、剪贴板记录、开机启动和截图权限 |

界面要求见 [02-ui-spec.md](02-ui-spec.md)，macOS 集成要求见 [03-macos-spec.md](03-macos-spec.md)。

## 功能规则

### 第一方插件

1. 每个插件具有稳定且唯一的标识、显示名称、版本、启用状态和能力声明。
2. 插件通过应用核心注册搜索结果、命令、菜单项、快捷键、设置项和所需权限。
3. 单个插件失败时，应用核心和其他插件继续运行；失败插件的功能页面和其他贡献隐藏，其失败状态保留在插件列表中。
4. 禁用插件后，应用核心注销该插件提供的功能页面、其他入口、快捷键和后台任务，并保留用户配置。
5. 插件只由项目所有者以源码形式提供，随主应用编译、签名和发布；产品不扫描或加载外部插件，不提供插件 SDK、插件市场或本地安装入口。
6. 插件与应用核心运行在同一进程，共享主应用已获得的系统权限和本地数据访问边界，不承诺进程级安全隔离。
7. 插件所需权限必须预先声明，并仅在用户首次触发相关能力时请求；禁用插件不会撤销已由 macOS 授予的权限。
8. 插件跟随主应用安装、升级和卸载，不提供独立升级或卸载操作。
9. 若未来允许用户或第三方安装插件，必须重新定义信任、签名校验、权限、数据访问、故障隔离、升级和卸载规则后再进入产品范围。
10. “设置 → 通用 → 插件管理”始终提供独立于插件贡献的插件列表；列表展示所有已注册插件的名称、版本和当前状态，并允许用户启用或禁用插件。启动失败时显示简短原因和“重试”操作。
11. 插件启动失败时保持启用开关开启，并将运行状态显示为“启动失败”；用户可手动重试，应用下次启动时也自动重试一次。只有用户主动关闭开关后，插件才进入“已禁用”状态并停止自动重试。

### 统一搜索

1. 统一搜索仅包含应用、文件、计算和内置命令四类来源，不包含剪贴板记录或设置项；各来源并发返回结果，单个来源失败不影响其他结果。
2. 有查询文本时，排序由来源基础优先级、文本匹配度和本地使用记录共同决定，最多展示 12 条结果；基础优先级依次为应用 100、内置命令 90、计算 85、文件 75。
3. 空查询页依次展示“常用操作”“最近使用”两个分区。常用操作固定为区域截图、窗口截图和全屏截图；最近使用最多展示 5 个应用或内置命令。空查询页不受搜索结果 12 条上限约束。
4. 空查询内容按结果稳定标识去重；常用操作优先展示，最近使用跳过已出现在常用操作中的项目，并继续向后补足最多 5 个不同项目。
5. 回车执行选中结果的主动作。
6. 命令栏每次打开时显示在指针所在显示器；无法确定指针所在显示器时回退到 `NSScreen.main`。
7. 产品不提供搜索结果黑名单、“隐藏此结果”、来源筛选或来源开关，也不占用 `⌘1–⌘6` 作为来源快捷键；四类来源随快速启动插件整体启停。
8. 统一搜索不展示剪贴板记录；“打开剪贴板历史”是唯一与剪贴板相关的内置命令，执行后打开独立历史窗口。用户也可通过菜单栏或全局快捷键打开该窗口，并只在窗口内搜索历史记录。
9. 统一搜索不展示设置项，也不提供“打开本应用设置”或“检查权限状态”命令；用户通过菜单栏或 `⌘,` 打开青鸟设置。
10. 应用和内置命令在输入至少 1 个字符后参与搜索，文件在输入至少 2 个字符后参与搜索；计算只在输入可解析的数学表达式或单位换算时返回结果。

### 应用、文件与计算

1. 应用来源扫描 `/Applications`、`~/Applications` 和 `/System/Applications` 中的应用。
2. 文件来源默认搜索 `~/Desktop`、`~/Documents` 和 `~/Downloads`；用户可在“设置 → 快速启动”通过文件夹选择器添加或移除任意目录，不限制目录位置、磁盘类型、数量或类别。添加时只拒绝重复目录，以及与已有目录形成父子覆盖关系的目录；无论已有目录是父目录还是子目录，都拒绝新增目录并指出冲突对象。
3. 文件结果按 `Enter` 使用默认应用打开，按 `⌘Enter` 在 Finder 中显示，按 `⌘C` 复制完整路径；选中后在命令栏底部显示三项快捷键提示，不提供动作面板或右键菜单。失效文件显示为不可用。
4. 计算在本机完成，结果可复制。
5. 添加重复目录或与已有目录形成父子覆盖关系时拒绝添加，并明确显示冲突目录；产品不自动删除或替换已有目录。
6. 搜索目录暂时不可用时保留配置并显示“不可用”，暂停返回该目录结果；目录恢复后自动重新建立索引。用户可手动移除不可用目录。
7. 文件索引递归遍历目录，不限制深度或文件数量，但不跟随目录符号链接。
8. 添加目录后立即在后台建立索引，不阻塞其他搜索来源；产品监听文件变化，新增、移动或删除的文件应在 5 秒内反映到搜索结果。
9. “设置 → 快速启动”展示每个搜索目录的“索引中”“可用”或“不可用”状态，并提供手动刷新操作。

### 剪贴板

1. 默认记录文本、图片和文件引用，保留期可选 7 天、30 天、90 天或永久，默认 30 天；用户可修改保留期或暂停记录。所有记录统一遵循保留期。
2. 同一次复制同时提供多种表示时只生成一条记录，内容优先级为文件引用、图片、富文本/HTML、纯文本。
3. 一次复制多个文件时保存为一条文件集合记录，保留文件顺序；任一文件失效时仅标记该文件，其他文件仍可用。
4. 重复内容按内容摘要合并，并更新最近一次出现时间。
5. 文件记录保存路径和元数据；源文件失效时将记录标记为不可用。
6. 数据保存在当前 macOS 用户设备。用户可在历史窗口删除单条记录；清空全部记录只能从“设置 → 剪贴板”发起。
7. 清空全部记录前必须确认；持久化失败不得改变当前系统剪贴板。
8. 剪贴板历史在应用启动满一小时后执行首次清理，之后每小时清理一次；应用启动时不清理。记录是否过期以其最近一次出现时间计算。
9. 修改保留期后立即保存新值，不提示、不立即删除；超过新期限的记录在下一次清理时直接永久删除。延长保留期不会恢复已经删除的记录。
10. 禁用剪贴板插件后停止新内容监听及该插件的界面入口，但应用级清理继续按既定保留期处理已有历史。
11. 剪贴板历史搜索仅筛选已保存的剪贴板记录，不调用或复用统一搜索。
12. 剪贴板记录所有能够读取的受支持内容，包括来源应用标记为敏感或临时的内容；产品不做敏感内容过滤，也不提供应用黑名单。
13. 剪贴板记录不提供置顶或收藏状态。
14. 剪贴板历史搜索至少输入 2 个字符；对纯文本、富文本纯文本内容、文件名和文件路径做大小写及重音不敏感的包含匹配。图片记录没有可搜索文字时不返回，但可按类型筛选。

### 截图与贴图

1. 区域、窗口和全屏截图共用一个入口和同一个截图状态。
2. 进入截图状态后自动高亮指针所在窗口；单击选择该窗口，按住左键拖拽改为区域选择，`⌘A` 选择指针所在显示器全屏。
3. 指针移动到其他显示器时，窗口检测、区域选择和全屏选择切换到该显示器。
4. 截图完成复制、保存、快捷保存或贴图后记为成功截图。成功截图进入当前运行期的截图记录。
5. 截图记录按成功时间排序，容量范围为 `1…200`，默认 20；满额时淘汰最早记录。
6. 标注支持矩形、箭头、直线、折线、文字和马赛克。导出内容只包含已完成的标注。
7. 贴图按图像、颜色、HTML、纯文本、文件路径的顺序解析剪贴板内容。
8. HTML 以本地富文本渲染；脚本和远程资源保持禁用。
9. 文件路径首次贴图时按设置解析本地图片；其他情况显示路径文本。
10. 关闭贴图后按最近关闭顺序进入恢复队列。恢复数量范围为 `0…20`，默认 1；销毁和关闭分组会永久移除对应贴图。
11. 截图记录、贴图和恢复队列只保留到本次应用退出。
12. 截图、复制、保存或贴图失败时保留当前可编辑状态并提供重试。
13. 从剪贴板创建的图片贴图保持原始宽高比，并以原始点尺寸作为初始尺寸；初始宽、高均不得超过当前操作显示器可见区域的 40%，较小图片不主动放大。
14. 纯文本、HTML、颜色和文件路径贴图的初始尺寸统一为 `420×280 pt`；所有贴图的最小窗口尺寸为 `80×60 pt`。
15. 由截图创建的贴图完整保留原截图区域的位置和尺寸，创建后不移动、不缩放，不受剪贴板图片贴图 40% 尺寸上限影响。
16. 从剪贴板创建的贴图出现在当前操作显示器可见区域中央；连续创建时，每张向右下偏移 `24 pt`，到达可见区域边缘后从中央重新开始。

### 内置命令

产品支持以下 11 项内置命令：

| 类别 | 命令 | 执行结果 |
|---|---|---|
| 导航 | 打开系统设置 | 打开 macOS 系统设置 |
| 导航 | 打开下载目录 | 在 Finder 中打开当前用户的下载目录 |
| 导航 | 打开应用程序目录 | 在 Finder 中打开 `/Applications` |
| 导航 | 打开桌面目录 | 在 Finder 中打开当前用户的桌面目录 |
| 截图 | 区域截图 | 进入统一截图状态并开始区域选择 |
| 截图 | 全屏截图 | 截取当前截图显示器 |
| 截图 | 窗口截图 | 截取指针所在窗口 |
| 剪贴板 | 打开剪贴板历史 | 打开独立剪贴板历史窗口 |
| 系统控制 | 重启 Finder | 终止并重新打开 Finder |
| 系统控制 | 重启 Dock | 终止 Dock，由 macOS 自动重新启动 |
| 系统控制 | 切换深色或浅色模式 | 在青鸟的深色与浅色外观之间切换 |

1. 内置命令由应用或第一方插件明确登记，用户输入只用于检索已登记命令。
2. 所有内置命令均在用户执行后立即运行，不设置二次确认。
3. 命令使用适合该动作的应用内能力、系统 API 或 Apple Events 执行；系统拒绝时显示原因和处理入口。
4. 命令使用记录只参与本地排序。
5. 产品不解析或执行用户输入的任意 shell 命令。

### 设置与欢迎向导

1. 设置包含 2 个固定页面：通用、关于。
2. 功能列表最多包含 3 个功能页面：快速启动、剪贴板、截图；仅显示已启用且启动成功的插件页面，每个功能独立管理自己的设置。
3. 通用页面管理插件、外观、语言、数据、权限等应用级设置；“插件管理”展示所有已注册插件，不受插件启停或失败状态影响。
4. 第一方插件需要用户配置时，在功能列表注册一个独立设置页面。
5. 设置修改即时保存到当前用户设备；无效配置保持原值。
6. 首次启动显示单屏欢迎向导；“开始使用”和“跳过设置”均记录完成状态。
7. 跳过欢迎向导前必须确认；关闭或未完成向导不阻断其他功能入口。
8. 通用页面的权限区域展示当前状态、重新检测和系统设置入口。
9. 关于页面读取当前 Bundle 版本与构建号，并提供更新、反馈、隐私政策和开源许可入口。
