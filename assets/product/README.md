# 发布素材清单 / Release Asset Checklist

> 本目录存放 README 与产品主页引用的真机截图素材。
> 当前为占位说明，**尚无实际图片文件** —— 请在发布前从已签名的构建版本截取后放入本目录。

## 为什么需要真机截图

- 截图与贴图功能当前由 `FeatureGate.screenshotEnabled = false` 关闭，无法演示，
  相关素材应等功能开放后补拍。
- 用 CSS 复刻的界面示意图只能作为过渡；正式对外传播应使用真实界面，
  避免与实际产品不符造成误导。

## 截取要求

1. 使用**已签名并公证的 Release 构建**，不要用 Debug 构建。
2. 统一使用浅色外观截取，保持品牌色 `#0A9488` 一致；如需展示深色模式，
   文件名加 `-dark` 后缀另存一份。
3. 截取前清空真实个人数据：剪贴板历史、文件搜索目录、最近使用记录，
   改用无隐私风险的示例内容（示例文本、示例文件名）。
4. 隐藏菜单栏中的个人信息图标，或用系统截图工具只截取应用窗口。
5. GIF 控制在 5 MB 以内、时长 15 秒内，避免仓库体积膨胀。
