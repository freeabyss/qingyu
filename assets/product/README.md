## 快速截取流程

1. 用**已签名并公证的 Release 构建**（推荐），或本地 `./start.sh build` 生成的
   Debug 构建；不要使用 Xcode Preview。
2. 准备一个**干净的桌面**：关闭无关窗口、隐藏通知中心与个人图标，
   把桌面壁纸换成纯色或清羽品牌底色，避免截图带出个人数据。
3. 打开清羽，按需切换到目标界面：
   - 命令栏：`⌥ Space`；空查询即为「常用操作 / 最近使用」，输入关键词得到四类结果。
   - 剪贴板历史：`⌥⌘C`；先复制几段示例文本 / 图片 / 文件引用作为演示数据。
   - 设置：`⌥⌘,`，选中「通用」页。
   - 欢迎向导：菜单栏图标 →「欢迎向导」。
4. 使用系统截图工具只截取应用窗口：`⇧⌘4` 后按 `空格`，把指针移到目标窗口上单击；
   或执行 `screencapture -i -o 输出路径.png` 选择窗口（不会拍摄整屏）。
5. 按上表命名并放入本目录；需要深色模式时文件名加 `-dark` 后缀另存一份。

> 提示：在终端运行 `screencapture -i` 只会截取你点选的那个窗口，不会把桌面
> 上的其他应用拍进去，适合在不能清空桌面时使用。

## 裁剪要求

1. 统一使用浅色外观截取，保持品牌色 `#0A9488` 一致；如需展示深色模式，
   文件名加 `-dark` 后缀另存一份。
2. 截取前清空真实个人数据：剪贴板历史、文件搜索目录、最近使用记录，
   改用无隐私风险的示例内容（示例文本、示例文件名）。
3. 隐藏菜单栏中的个人信息图标，或用系统截图工具只截取应用窗口。
4. GIF 控制在 5 MB 以内、时长 15 秒内，避免仓库体积膨胀。
